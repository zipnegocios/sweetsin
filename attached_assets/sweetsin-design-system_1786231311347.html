04 — Motion Design

Animation choreography

WebGL
Hero Particle Field
Three.js / custom shader. Partículas forman la silueta del devil mascot al cargar la página, luego se dispersan suavemente en loop. On hover: aceleran y cambian a rojo más intenso.
THREE.Points + custom vertex shader
Noise-based displacement
~2000 particles, 60fps target
GSAP
Hero Headline SplitText
Cada letra del headline entra con clipPath + y offset con stagger 0.03s. Duración 1.2s, ease power4.out. Se activa después de 0.4s del page load.
gsap.from(chars, {
  yPercent: 100,
  clipPath: 'inset(0 0 100% 0)',
  stagger: 0.03,
  duration: 1.2,
  ease: 'power4.out'
})
ScrollTrigger
Section Line Reveal
Cada línea de texto en brand story y spotlight entra con clipPath top → bottom al scrollear. El efecto "wiping" sugiere que el texto emerge del papel. Scrub: false, una vez.
gsap.from(lines, {
  clipPath: 'inset(0 0 100% 0)',
  y: 20,
  stagger: 0.08,
  scrollTrigger: { trigger, start: 'top 75%' }
})
GSAP
Menu Cards Stagger
Al entrar el grid en viewport, las cards entran desde abajo con stagger 0.06s. Combinado con fade in opacity 0 → 1. Hover: translateY(-4px) + box-shadow red glow.
gsap.from('.menu-card', {
  y: 40, opacity: 0,
  stagger: 0.06,
  duration: 0.7,
  ease: 'power2.out',
  scrollTrigger: {…}
})
WebGL
Repolla Particle Effect
Partículas de color arequipe-gold flotando alrededor de la foto del producto. Movimiento lento, orgánico. Reacciona al cursor del usuario (mouse parallax leve).
WebGL canvas overlay
HSL: #C9943A particles
Mouse: lerp(target, mouse, 0.05)
UX
Custom Cursor
Cursor personalizado: círculo rojo pequeño que sigue al mouse con lag suave. Al hacer hover sobre links/buttons, se expande y cambia a fill completo. Desktop only.
gsap.to(cursor, {
  x: mouseX, y: mouseY,
  duration: 0.3,
  ease: 'power2.out'
})
GSAP
Navbar Transformation
Nav transparente en hero → sólido navy con blur backdrop al scrollear 80px. Transición suave 0.4s. Logo y links cambian de opacidad al trigger. Sticky top.
ScrollTrigger.create({
  start: '80px top',
  onEnter: () => nav.classList.add('scrolled'),
  onLeaveBack: () => nav.classList.remove('scrolled')
})
GSAP
Counter Animation
Los números estadísticos en Brand Story (7+ productos, 100% homemade, 0 regrets) cuentan animados al entrar en viewport. Ease power1.inOut, 1.5s.
gsap.to(counter, {
  innerText: targetValue,
  snap: { innerText: 1 },
  duration: 1.5,
  ease: 'power1.inOut'
})
Page
Page Transition
Entre páginas internas (menu detail, checkout): overlay rojo full-screen que entra, página siguiente carga, overlay sale. 0.5s in, 0.5s out. Evita flash blanco.
// Enter
gsap.to(overlay, { scaleY: 1, transformOrigin: 'top', duration: 0.5 })
// Exit
gsap.to(overlay, { scaleY: 0, transformOrigin: 'bottom', duration: 0.5 })

Mobile-specific behaviors

🧭
Bottom Navigation Bar
Mobile tiene una sticky bottom nav con 4 tabs: Menu, Events, Order, Find Us. Thumb-friendly, siempre visible. Desaparece al scrollear down, reaparece al subir.
👈
Horizontal Scroll en Menú
En mobile, el grid de productos se convierte en scroll horizontal con snap points. Las cards miden 80% del ancho de pantalla para sugerir que hay más.
⚡
WebGL Desactivado en Mobile
En dispositivos con < 4GB RAM o conexión lenta, el WebGL particle effect se reemplaza con una imagen SVG del mascot animada con CSS. Fallback automático.
📞
Tap to WhatsApp
En mobile, el CTA de eventos abre un mensaje de WhatsApp pre-llenado a Oscar. Friction mínima para consultas B2B desde teléfono.

08 — UX Principles

Diseño de experiencia

🎯
Un CTA dominante por sección
Cada sección tiene exactamente una acción primaria clara. No se compite con CTAs secundarios del mismo peso. El usuario siempre sabe qué hacer.
📸
Fotografía como copy
Las fotos del producto venden antes que el texto. Invertir en fotografía artesanal de alta calidad es tan importante como el código. El diseño está construido alrededor de imágenes great.
⚡
Menos a más
Animaciones que se revelan en scroll, nunca al cargar. La página empieza quieta y cobra vida mientras el usuario explora. Sin autoplays agresivos.
🛒
Preorder friction mínima
Del Hero al checkout en 3 clicks máximo. Sin registro obligatorio, sin creación de cuenta. Checkout como invitado siempre disponible. Email para recibo solamente.
📱
Touch-first interactions
Tap targets mínimo 44×44px. Swipe horizontal en menú. Formularios con teclado numérico donde corresponde. El hover no es una feature en mobile.
♿
Accesibilidad WCAG AA
Contraste 4.5:1 mínimo en todo texto. Focus states visibles para navegación por teclado. Alt text en todas las fotos. Animaciones respetan prefers-reduced-motion.

Design philosophy

"A site worthy of the product. A product worthy of the site."

Sweet Sin tiene una identidad de marca excepcional. El sitio web no solo la refleja — la amplifica. Cada pixel justifica el precio de las obleas.
